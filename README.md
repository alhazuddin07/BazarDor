বাজার দর (BazarDor)

📌 Project Description

BazarDor is a web application that helps users explore daily market prices and product information in one place. Users can browse products by category, view product details, and track price changes through a simple and responsive interface.

🛠️ Technologies Used

Next.js — Building the user interface.

Next.js App Router — Handling page navigation and routing.

TypeScript — Writing type-safe and maintainable code.

Tailwind CSS — Styling and responsive design.

DaisyUI — Building reusable UI components.

Better Auth — Handling user authentication and Google sign-in.

React Toastify — Displaying success and error notifications.

✨ Key Features

Daily Market Prices — View daily prices of available market products.

Category-Based Browsing — Explore products by category.

Product Details — View detailed information about individual products.

Price Change Indicators — Identify whether product prices have increased or decreased.

User Authentication — Sign up, sign in, and authenticate using Google with Better Auth.

📱 Responsive Design

BazarDor is designed to provide a user-friendly experience across desktop, tablet, and mobile devices using Tailwind CSS and DaisyUI.
